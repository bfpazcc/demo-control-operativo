Pasos para la Entrega o Instalación en el Servidor del Cliente

  1. Configuración del Servidor Nube / VPS ($4 - $6 / mes costo directo servidor):

    Se instala Docker y la aplicación en un servidor Linux (Ubuntu/Debian) en minutos.

  2. Vinculación del Dominio del Cliente:

    Se agrega un registro CNAME o A en el DNS del dominio del cliente (ej: GoDaddy, Namecheap o Cloudflare).

  3. Base de Datos Relacional Abierta:

    SQLite para PyMEs pequeñas o PostgreSQL / Supabase para almacenamiento masivo multi-obra.

  4. Instalación de App Móvil PWA en Teléfonos de Operadores:

    Sin pasar por Google Play / App Store. Se añade directo al inicio del smartphone como App nativa.
